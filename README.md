# ①課題名
0.5秒の勇者
※レスポンシブ未対応なので、PC推奨※

## ②課題内容（どんな作品か）
じゃんけんクエスト要素を追加。出し手に応じて与えるダメージを割り当てて、CPUと対戦しHP残量が先に無くなったほうが負け。

あくまでクエストなので、CPUの手が見えてから出し手を決められますが、1秒以内に出し手を選択しないとMissでプレイヤーが失点。

さらに、反応速度が早ければ早いほどボーナスで与えるダメージが大きくなります。  

ただし、素早く出した手を間違えて負けた手を出すと点数が大きくなる。

## ⑤工夫した点・こだわった点
JSの特性である条件分岐を多分に使っています。
- 出し手ごとの勝敗（通常じゃんけんのロジック）
- 出し手ごとの点数
- 反応速度に応じた点数倍率
- 反応できなかった場合の点数付与
- HP残量が0になった場合に、ゲームを終わらせる、などなど



また、JSにより、ユーザー行動ごとに表示を変えていくことができました。
- タイマー表示
  - 開始をクリックしてから、敵の出し手を出すまで3秒のカウントダウン
  - 難しいかなと思ったら、意外と単純でした
- バトルログを徐々に増やす
- 勝ち・負け・あいこ・Missでバトルログの表示の色を変える
- HP残量バーを減らす
